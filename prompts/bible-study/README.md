# Bible study prompts (Back to the Bible)

## Files

| File | Use |
|------|-----|
| `01-writing-prompt.md` | Step 1 — PDF/Word → structured text |
| `02-import-template.json` | Step 2 — structured text → uploadable JSON |
| `03-one-shot-prompt.md` | Optional — PDF + template in one Gemini/ChatGPT session |

## After import

Open `/resources` → **Back to the Bible** → paste or import JSON → set **date** and **hero image** → publish.

Required fields for publish: title, description, passage, scripture reading (NKJV), sections, discussion questions, 3+ quiz questions, at least 1 tag.
